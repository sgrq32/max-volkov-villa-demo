# Casa Avela — Villa Demo

![Screenshot placeholder](./docs/screenshot-placeholder.png)

A fictional luxury villa rental experience focused on visual storytelling and mobile booking UX.

## Features
- Fullscreen responsive gallery lightbox
- Editorial rooms, amenities, nearby and house-rules sections
- Date selection and live night × demo-rate calculation
- Demo booking success state, accessible metadata and favicon

## Stack
Next.js 16 · React 19 · TypeScript · CSS

## Local development / build
```bash
npm install
npm run dev
npm run build
npx vercel --prod
```
