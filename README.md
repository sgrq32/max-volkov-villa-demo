# Casa Avela — Villa Demo

## Overview
A fictional luxury villa rental experience focused on visual storytelling and mobile booking UX.

## Features
- Responsive fullscreen gallery lightbox
- Editorial rooms, amenities, nearby and house-rules sections
- Date selection and live night × demo-rate calculation
- Demo booking success state
- SEO, Open Graph metadata and custom favicon

## Stack
- Next.js
- React
- TypeScript
- CSS

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
